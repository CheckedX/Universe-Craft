# Universe Craft - 小说宇宙构建者

> **一个用故事教知识的宇宙构建工具。**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## 核心理念

> 知识不是塞进去的，是长出来的。

传统的知识学习是「**概念 → 解释 → 例子**」的线性灌输。
Universe Craft 的方式是「**故事 → 隐喻 → 顿悟**」的自然涌现。

用户说出一个概念，系统不讲概念——而是**用故事把它包裹起来**，让知识在情节的缝隙中自然渗透。

---

## 功能特性

### 🎯 可持续生长的故事宇宙

**像养一个角色扮演游戏存档。**

- 每次创作不重置，而是**累积**：角色会记住自己做过的事
- 新的故事**承接旧的设定**：同一个角色在不同概念下会有不同的故事彩蛋
- 最终形成一张**角色与故事的网**：你知道这个宇宙里谁是谁、谁去过哪里、发生过什么

| 传统方式 | Universe Craft |
|----------|----------------|
| 每次创作孤立 | 角色、故事、地点持续累积 |
| 概念孤零零存在 | 概念被故事「活过」，有温度 |
| 学完就忘 | 有回味的宇宙，随时可以回来 |

### 📚 学习任何领域的知识

**不挑领域，没有门槛。**

- 🔬 科学理论（熵增、量子纠缠、薛定谔的猫）
- 🧠 哲学概念（囚徒困境、第一性原理、存在主义）
- 💼 职业知识（编译器原理、博弈论、设计模式）
- 🌱 生活智慧（沉没成本、复利效应、二八法则）

只要你给出一个概念，系统就会为它**量身打造一个故事**，让概念在情节中显现。

### ✨ 知识自然融入，而非刻板拼凑

**这是最关键的区别。**

系统遵循一个铁律：**故事全程不出现概念名称和领域术语。**

- ❌ 不会说「囚徒困境是指...」
- ❌ 不会解释「薛定谔的猫是量子力学...」
- ❌ 不会列举「博弈论有以下几个特点...」

知识藏在：
- 角色的一句话
- 情节的一个转折
- 结尾的一句话点题

> 读者读完故事，概念已经在心里了——这不是灌输，是「悟」。

## 快速开始

### 方式一：手动导入（通用）

适用于所有支持 Skill 的 AI Agent 平台。

#### 步骤

1. **下载 Skill 文件**
   ```bash
   git clone https://github.com/CheckedX/Universe-Craft.git
   cd Universe-Craft
   ```

2. **获取 SKILL.md 内容**
   ```bash
   cat SKILL.md
   ```

3. **导入到你的平台**

   **Coze 平台**：
   - 进入扣子控制台 → 创建 Agent → 找到「导入 Skill」或「自定义 Skill」选项
   - 将 SKILL.md 的全部内容粘贴进去

   **其他 OpenClaw 平台**：
   - 参考各平台的 Skill 导入文档
   - 通常需要将 SKILL.md 放在特定目录下

4. **开始使用**
   ```
   用户：请帮我整理《XXX》的世界观设定
   ```

### 方式二：Coze 商店（推荐）

在 Coze 平台直接搜索安装。

#### 搜索安装步骤

1. 访问 [Coze 商店](https://www.coze.cn/store/bot)
2. 搜索「Universe Craft」或「小说宇宙构建者」
3. 点击「使用」或「添加到我的 Bot」

> ⚠️ 商店版本可能需要等待审核，通过后即可搜索到。

## 常见问题

### Q: 导入后无法使用？

**检查项**：
1. SKILL.md 文件格式是否完整
2. 平台是否支持自定义 Skill
3. 是否有语法错误

### Q: 设定文件存哪里？

**建议**：
- 每次对话开始时粘贴上次保存的设定文件
- 或使用平台的记忆/知识库功能

### Q: 如何分享我创建的宇宙？

将设定文件导出为 `.md` 文件，分享给其他 Universe Craft 用户即可直接使用。
