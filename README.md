# Universe Craft - 小说宇宙构建者

一个可持续生长的跨平台小说宇宙构建工具。

## 功能特性

- 🎯 **智能追问**：先问清需求再动手，确保理解准确
- ✏️ **可修改润色**：每步完成后允许用户调整
- 🔄 **可持续生长**：设定文件自动累积，宇宙不断丰富
- 📚 **跨平台兼容**：支持 Coze、ClawHub 及所有 OpenClaw 框架平台

## 快速开始

### 方式一：手动导入（通用）

适用于所有支持 Skill 的 AI Agent 平台。

#### 步骤

1. **下载 Skill 文件**
   ```bash
   git clone https://github.com/YOUR_USERNAME/universe-craft.git
   cd universe-craft
   ```

2. **获取 SKILL.md 内容**
   ```bash
   cat SKILL.md
   ```

3. **导入到你的平台**

   **Coze 平台**：
   - 进入扣子控制台 → 创建 Agent → 找到「导入 Skill」或「自定义 Skill」选项
   - 将 SKILL.md 的全部内容粘贴进去

   **其他 OpenClaw 平台**：
   - 参考各平台的 Skill 导入文档
   - 通常需要将 SKILL.md 放在特定目录下

4. **开始使用**
   ```
   用户：请帮我整理《XXX》的世界观设定
   ```

### 方式二：Coze 商店（推荐）

在 Coze 平台直接搜索安装。

#### 搜索安装步骤

1. 访问 [Coze 商店](https://www.coze.cn/store/bot)
2. 搜索「Universe Craft」或「小说宇宙构建者」
3. 点击「使用」或「添加到我的 Bot」

> ⚠️ 商店版本可能需要等待审核，通过后即可搜索到。

### 第一步：创建新宇宙

```

Agent：请描述你最想构建的哈利波特宇宙方面——是霍格沃茨学院设定、魔法世界法则、还是魔法生物体系？

```

## 自定义配置

### 修改追问模式

在 SKILL.md 中找到「追问原则」，可调整为：
- 激进模式：更少的问题，快速产出
- 保守模式：更多的问题，精准理解

### 修改输出格式

在「输出格式」部分可自定义：
- 调整章节顺序
- 增加/删除字段
- 修改篇幅限制

## 常见问题

### Q: 导入后无法使用？

**检查项**：
1. Skill 文件格式是否完整
2. 平台是否支持自定义 Skill
3. 是否有语法错误

### Q: 设定文件存哪里？

**建议**：
- 每次对话开始时粘贴上次保存的设定文件
- 或使用平台的记忆/知识库功能

### Q: 如何分享我创建的宇宙？

将设定文件导出为 `.md` 文件，分享给其他 Universe Craft 用户即可直接使用。
